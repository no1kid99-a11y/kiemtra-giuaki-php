# Kiểm tra PHP lớp 01

## Bài 1
Kiểm tra số nguyên tố và hiển thị các số nguyên tố từ 1 đến 100.

## Bài 2
Quản lý thông tin sản phẩm bằng mảng kết hợp với các khóa `name`, `price`, `quantity`, hiển thị sản phẩm và tính tổng giá trị.

## Chạy bằng XAMPP
Đặt thư mục này vào:

`C:\xampp\htdocs\kiem-tra-php\`

Sau đó bật Apache và mở:

`http://localhost/kiem-tra-php/`

Hoặc:
- `http://localhost/kiem-tra-php/bai1.php`
- `http://localhost/kiem-tra-php/bai2.php`
